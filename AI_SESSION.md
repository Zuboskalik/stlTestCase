# Ключевые промпты сессии с ИИ

Формулировки сокращены по ходу сессии. Исходная задача и правила проверки приведены здесь для воспроизводимости.

1. Проект уже запущен на http://localhost:8000/ согласно README.md в корне репозитория. Реализовать задачи, указанные в блоке "Функциональные требования". PDF использовался как источник этого блока.
2. "В корне репозитория в итоге должно быть: README: как запустить, что сделано и что нет. Сессия работы с ИИ-агентом: экспорт или ключевые промпты, в репозитории".
3. "Если нужно проверить отображение на desktop (1440x900) и mobile (375x812), порядок блоков, горизонтальное переполнение или валидацию форм - используй одноразовый headless-скрипт Node.js и Playwright. В чат выведи краткий текстовый отчёт PASS/FAIL". Скриншоты не запрашивались.
4. "Продолжить". К этому моменту пересчёт за октябрь был применён через новый экран и проверен повторным POST. После команды оформлены результаты и завершены проверки.

## Решения, принятые в сессии

- Для рейсов без положительного объёма использован вес, а при нулевом весе - равные доли. Копейки распределены по наибольшим остаткам с разрешением равенства по ID клиента.
- Предпросмотр и применение используют один расчёт. При пересчёте сохранены статусы счетов и даты бизнес-операций.
- Октябрь применён на запущенном локальном проекте. Таблица в README взята из экрана после подтверждения.
